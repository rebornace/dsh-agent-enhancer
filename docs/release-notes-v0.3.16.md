# v0.3.16 — 演示录制：你做一遍，智能体照着做

## 新增

- **演示录制**（设置 → 功能 → 浏览器 Agent → 演示录制，默认关）
  - **你发起**：右侧栏浏览器面板 →「开始演示」→ 在专用浏览器里操作一遍 →「结束并查看步骤」。步骤直接显示在面板里，可**复制**，也可**发给智能体**（作为引用插入输入框，确认后发送即可）。
  - **智能体发起**：在对话里说「我演示给你看」「我做一遍你记住」这类话，它会打开页面并弹出人工卡片；你操作完点「已完成，继续」，步骤就回到模型。
  - 记录点击 / 填写 / 回车 / 页面跳转；密码、验证码、token、卡号类字段只记 `***`。
  - 步骤实时回传，页面跳转不会丢；点进输入框那一下不会多出一条点击。

## 适合什么场景

- 某个后台的导出 / 审批流程，你说不清，但做一遍很快。
- 想固定一套操作让智能体以后照做（步骤会以「角色 + 名称」描述，模型重放时会先重新读页面）。
- 排查「为什么它点错了」：你自己做一遍，对比它记录的步骤和实际页面。

## 边界

- 只记录**当前绑定的标签**以及它打开的新标签；你在别的标签里操作不会记录。
- 不截屏、不记录网络请求（那是「调试与页面模拟」开关负责的事）。
- 步骤里的选择器是给人看的；模型重放时走 `browser_snapshot` + 按角色/名称操作，因为每次运行的元素编号都不同。

## 安装

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.16
```

或在 Desktop「设置 → 插件」搜索 `dsh-agent-enhancer`，安装后重启。
