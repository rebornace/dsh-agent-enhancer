# v0.3.23 — 两处界面修正

## 设置页

功能列表里的开关改成**与功能标题顶部对齐**。浏览器 Agent 这类条目下面还挂着浏览器选择、调试、演示录制、闲置回收，整块很长；原来开关垂直居中，看起来像飘在中间。

## 右侧浏览器面板

- **不再压住内容**：面板主体自己滚动，步骤再多也只在面板内滚，不会溢出盖住下面的区块。
- **层级更清楚**：「演示录制」独立成一段（上方有分隔线），不再和标签列表粘在一起。
- **步骤明细成卡片**：展开的流程步骤有边框、圆角和自己的滚动区，长流程不会把整页拉长。
- **标签列表有边界**：可选标签是一个带边框的滚动区，和下面的区块一眼能分开。

## 升级

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.23
```

或在 Desktop「设置 → 插件」里更新后重启。
