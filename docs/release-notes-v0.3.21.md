# v0.3.21 — 网站改版后，流程会自己长回来

## 新增

- **流程修复**：保存的流程卡住时（控件改名、多了一步弹窗），智能体接着把这件事做完，然后问你要不要记住：
  > 第 4 步的控件变了，现在改用「开始日期」。要记住这次的做法吗？　[记住] [只这一次]

  - **记住**：写回流程，下次直接用新位置；旧版本保留，可「撤销上次修改」。
  - **只这一次**：流程不动，下次照原样再试。
  - 只修**定位**，不改**动作**：填写值、步骤顺序都沿用录制时的；网站真的大改就如实停下，不硬编。
  - 密码类字段永远不参与修复，也不会被存进流程。
- **智能体也能发起**：`browser_demo_recipes { action: "heal" }` 记录建议，`accept: true` 才写回；流程列表会标出「有修复待确认」。

## 为什么值得

正常跑仍然是纯代码重放，不花 token；只有在网站变了、重放卡住的那一次，模型才介入。对比「每次都让模型现场点」，这是「偶尔贵」而不是「一直贵」。

## 说明

- 默认手动确认。无人值守的自动适应（同源 + 只改定位 + 尝试次数上限）留到后续版本，并会配独立开关。
- 按钮名字没变、含义变了（导出 CSV 变成导出 PDF）这类变化识别不出来，破坏性操作仍需逐次批准。

## 安装

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.21
```

或在 Desktop「设置 → 插件」里更新后重启。
