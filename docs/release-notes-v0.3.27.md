# v0.3.27 — 审批判断接上官方策略

## 改了什么

上一版只读「权限预设的名字」，这一版同时读**官方审批策略**：

| 官方状态 | 浏览器变更 |
| --- | --- |
| 预设「仅可查看」 | 直接拒绝（优先级最高） |
| 预设「自动审查」 | 交给官方审查器，不弹我们的卡 |
| 审批策略「从不询问」 | 视为完全访问，不再询问 |
| 预设「完全权限」 | 同上 |
| 「工作区内修改」+ 允许询问 | 保留本地卡 |
| 旧宿主（两个服务都没有） | 保留本地卡，日志说一次 |

好处是：像「工作区内修改 + 从不询问」这种自定义组合、以及以后新增的预设，都不会再被多问一遍。

## 这一版为什么没有把批准卡整个搬到官方

原计划是让浏览器审批走官方的 `tools/pre-execute`，只留一张卡。动手前核对官方审批能力时发现两个硬限制：

- 官方审批只提供「允许一次 / 拒绝」，**没有「本站本会话」**；
- 官方的 `ask` 提示只有文字，**没有控件截图预览**。

结果是：在「工作区内修改」下跑一个多步骤修复，会从「一次本会话放行」变成「每点一下弹一次卡」。这是明确的退步，所以这一版只做「读对策略、不去重复打断」，保留本地卡的站点放行与缩略图。这条决定已写进 `AGENTS.md`，避免以后又被“顺手统一”掉。

## 升级

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.27
```

或在 Desktop「设置 → 插件」里更新后重启。
