# DSH Agent Enhancer — 迭代路线

本文记录产品方向与后续迭代参考，便于按优先级推进，而不是一次做完所有能力。

## 产品原则

- **一个插件**：装上后尽量接近主流 Agent（Cursor / Claude / ChatGPT）的日常手感。
- **贴合原生**：优先增强官方已有入口与槽位，避免另开独立「网站式」面板。
- **简洁易用**：渐进披露；默认路径短；高级能力可关。
- **诚实数据**：上下文占用等数字标「约」，不伪装成账单级精确。

## 当前迭代 — 原生上下文下钻（P0）

用户仍点右下角官方占用环 → 官方面板三大类 → 点击某一类 → **官方右侧栏**打开分类明细（约 token 降序 + 占比条）→ 再点条目看二级全文/工具 schema。

已交付方向：官方 `sidebarRight.openTab` 页签，非浮动弹层。

已补：窗口余量、压缩/裁剪标记、消息再拆（用户/注入/助手/工具结果）、右侧栏一键官方 `/compact`。后续可做：跳转 transcript 高亮。不做：跨会话仪表盘、独立 Context 网页（`dsh-context` 类产品）。

## 后续参考（按推荐顺序）

### P0 — 会话手感（高 ROI、贴原生）

1. **Checkpoint 时间线打磨** — 已交付首版  
   入口：底部「N 轮 M 步」→ 会话统计弹层点「会话统计」；用户消息旁「检查点时间线」图标。右侧栏按轮展示覆盖（文件/部分/仅对话）、提示词摘要、文件变更与捕获缺口；行内「恢复到这里」。后续可补：与当前磁盘的 diff 对比、失败原因更深钻取。

2. **@ / 上下文挂载面板**  
   快速挂文件、目录、diff、终端摘录等，提升「模型吃什么」的可控感。

3. **Rules / Skills 管理壳**  
   可视化启用/编辑 AGENTS.md 与 skills；官方有机制，缺好用的壳。

### P1 — 外接世界（主叙事）

4. **侧栏浏览器 Agent**  
   打开页、读 DOM、点击输入、截图回传；安全：白名单 + 逐步授权。  
   **优先于 Computer Use。**

5. **Plan 入口产品化**  
   一键进入 `/plan`、计划卡片、批准后执行；和大改动确认绑定。

### P2 — 以后再说

6. **Computer Use**  
   演示强、稳定性与误操作风险高；作浏览器之后的兜底。

7. **云端长任务 / 多端同步 / 连接器全家桶**  
   偏平台能力，个人插件难做成官方级。

## 明确不做（或暂缓）

- 复制 `dsh-context` 的完整分析站。
- 与官方实验性「定时任务 / Agent 团队」抢首发（可待稳定后再增强体验）。
- 营销式夸大描述（awesome / 市场条目保持功能事实）。
