# v0.3.17 — 演示录制能自己重放，批准弹窗看得清也看得见

## 演示录制

- **跨标签**：专用浏览器里**所有已打开的标签**都会被记录（包括录制开始前就开着的），每步标出发生在哪个标签，重放时按标签切换。
- **录制角标**：每个被录的标签右下角显示「演示录制中」，结束后消失；不拦点击、不进快照。
- **一键重放**：`replay: true` 让你说完「我做一遍，然后你来」就真的由浏览器自己跑一遍，不用再等模型读步骤。遇到密码等被掩码字段、下拉框、找不到的控件会**停在那一步**并告诉你还剩哪些，不会假装跑完。
- **SPA 路由**：React / Vue 这类站点用 `pushState` 换路由也会记成一步导航。

## 批准弹窗

- **不再透明**：之前用了一个主题里不存在的颜色变量，整条背景被浏览器丢弃，卡片透在网页上。现按官方卡片配方重写，亮色暗色都不透明。
- **不再压住右侧栏**：侧栏展开时卡片自动左移，全屏侧栏也不会把卡片挤出去。
- **键盘**：`Enter` 允许本次、`Esc` 拒绝；在输入框打字时不会误触发。
- **看得到目标**：点击 / 输入类批准会显示目标控件的小块预览图，批准的是看得见的东西。

## 修正

- 客户端样式里 23 个不存在的设计 token（边框、字号、圆角因此一直没生效）全部换成真实 token，并加了守卫测试：CSS 里出现主题未定义的 token 就让 CI 失败。

## 适合什么场景

- 后台导出 / 审批流程：「我操作一遍，你照着做」。
- 跨标签的流程：A 页查数据，B 页填表提交。
- 批准前想确认「它到底要动哪个按钮」。

## 边界

- 录制只覆盖专用浏览器（这个独立 profile），不碰你日常浏览器的登录态。
- 重放只做录制范围内的动作；被掩码的密码、下拉选择、勾选框会停下来交给你或模型继续。
- 预览图只在批准时截一次，随请求一起丢弃，不落盘。

## 安装

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.17
```

或在 Desktop「设置 → 插件」里安装后重启。
