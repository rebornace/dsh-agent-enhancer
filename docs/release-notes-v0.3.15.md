# v0.3.15 — 调试采集与快照阅读体验

0.3.14 之后的一批修复与打磨，另加宿主依赖对齐 Desktop 0.2.2-rc.5。

## 修复

- **调试采集不再"假关闭"**：以前关掉开关只是拒绝工具调用，监听器仍在往缓冲里写。现在关开关会真正停止采集并丢弃缓冲；重新打开复用同一批监听器，不会出现重复条目。
- **采集只读当前标签**：`browser_network` / `browser_console` 默认只读会话绑定的标签，多标签调试不再混页；需要全量时传 `allTabs: true`，被过滤的条数会在回复里说明。
- **快照控件前置**：链接密集页以前把搜索框、按钮排在 80 条的最后，读起来像「全是链接」。现在控件排在最前，链接其后。

## 变更

- **闲置标签可按需设置**：关闭时间从固定 10 分钟改为 **10 / 30 / 60 分钟 / 不自动关闭**（默认 10 分钟）。0.3.14 的布尔配置自动映射，升级后行为不变。
- **开关改名**：「调试工具」→「**调试与页面模拟**」，说明里写清它同时管网络/控制台读取与深色模式、视口模拟。
- **宿主依赖对齐 Desktop `0.2.2-rc.5`**：构建与测试基准升到 rc.5，`peerDependencies` 放宽为 `>=0.2.2-rc.2 <0.3.0-0`，还停在 rc.2 的 Desktop 也能加载。已逐文件核对 rc.2→rc.5 的源码差异，对插件用到的槽位与类型均为新增。

## 安装

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.15
```

或在 Desktop「设置 → 插件」搜索 `dsh-agent-enhancer`，安装后重启。
