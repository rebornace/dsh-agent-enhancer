# v0.3.28 — 离线跑：给流程一个「允许无人值守」

## 问题

官方定时任务新建的会话固定是「工作区内修改 + 允许询问」，而任务本身不能改权限。所以定时跑一个保存的流程时，我们的批准卡一定会弹，且没人点——任务卡死。

## 方案

不动机器级权限，也不去猜“这是不是定时任务”，而是让**你**对某条流程做决定：

展开保存的流程 →「**允许无人值守**」。开启后，智能体运行这条流程时：

- 只对这个流程**录制时的站点**临时放行；
- 时长 **20 分钟**、最多 **30 个动作**；
- 流程本身、以及它卡住后的修复点击，都不再逐次弹卡；
- 时间或次数用完，自动回到逐次批准；
- 换站点、换会话都不生效；
- **密码类字段仍然停下等人**（这条永远不变）。

默认关闭；没有记录站点的流程不能开启（按没有站点信息，无法安全限定范围）。

## 定时任务现在怎么跑

1. 给你的流程打开「允许无人值守」。
2. 在官方「自动化任务」里写提示词：`跑一下「周报导出」`（可带上站点）。
3. 到点后：新会话照旧是工作区内修改，但这条流程在它自己的站点上不再等批准；跑完给你结果，卡住（例如要密码）会停下并说明。

## 提醒

在授权窗口内，智能体在这个站点上的点击不再逐次询问——相当于你提前批准了“这条流程以及为修好它所需的操作可以在这个站点执行”。所以默认关闭，只对你亲手录的流程开。

## 升级

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.28
```

或在 Desktop「设置 → 插件」里更新后重启。
