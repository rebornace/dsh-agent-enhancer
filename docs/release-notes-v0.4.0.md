# v0.4.0 — 演示流程收口

这一版把 0.3.20 起的「演示流程」批次收成一个里程碑：录一次，之后让智能体去跑，出了偏差能修，没人看着也能授权运行，跑完还知道结果。

## 流程

- **录制与重放**：演示一遍，保存为流程；对话里说「跑一下『周报导出』」即可，重放走一次批准。
- **参数说人话**：变量名取自页面标签（「开始日期」），日期给选择器，也能直接说「上周」「本月」「上季度」；缺值时会用一句人话问，而不是回一串变量名。
- **改版能修**：站点把控件改名后，智能体会补完剩余步骤，再问你要不要记住这次的做法；写回留版本，可「撤销上次修改」。
- **无人值守**：每条流程单独开启，只在录制时的站点生效，限时 20 分钟 / 30 次动作；密码类字段仍然停下等人。
- **运行结果**：每个流程记下上次跑的时间与结果，没跑完时行上有标记。

## 界面

- 流程行只留常用动作（运行 + ⋯），重命名 / 删除收进菜单，删除要二次确认。
- 展开后按用途分区：可改的值 / 运行方式 / 步骤（默认折叠）。
- 修掉了窄面板里卡片与按钮互相压住的问题（盒模型统一、步骤卡独立滚动）。

## 登录环境

- 专用浏览器不再暴露 `navigator.webdriver`（用页面初始化脚本，而不是会在 Chrome 顶部挂警告条的命令行参数）。B 站这类登录风控不会再因为这个标记直接拒绝；检查更多信号的站点仍需单独看。

## 移除

- **流程自动适应**（设置里的开关）：不再在没人看的时候改写流程；无人值守由每条流程的临时授权覆盖，修复只需点一次「记住」。

## 版本说明

仍然是 `0.x`：DeepSeek Desktop 本身还在预发布，插件不宣称比宿主更稳定。`1.0.0` 等宿主离开预发布再谈。

## 升级

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.4.0
```

或在 Desktop「设置 → 插件」里更新后重启。
