# v0.3.18 — 演示一次，存成流程，下次一句话再跑

## 新增

- **演示流程可复用**（设置 → 功能 → 浏览器 Agent → 演示录制 需开启）
  - 录完点「保存为流程」，右侧栏浏览器面板会列出已保存的流程（名称 + 步数）。
  - 每个流程有「运行 / 删除」：运行会按录制时的角色和名称重放一遍；遇到密码、下拉框或页面上找不到的控件，会停在那一步并告诉你原因，不会乱点。
  - **智能体发起的录制也能保存**：在对话里说「打开某站，我点一遍给你看」，录完切到侧栏会看到「上次录制：N 步」。
- **流程跨会话、跨重启可用**：保存时只留脱敏后的步骤和页面地址，不保存录制那次的内部标签 id；重启后运行会按页面 URL 重新找到标签，必要时重新打开起始页。

## 体验修正

- **批准弹窗的目标预览更稳**：以前目标控件如果刚被重新抓取过，预览会静默缺失；现在只要页面上还有标记就会截。
- **重放会先回到录制起始页**：录制前打开的页面不算在步骤里，重放时自动补上，避免在错误的页面上找控件。
- **出错信息更具体**：找不到控件时带上当前 URL，一眼能区分是页面不对还是控件变了。

## 升级说明

- 已保存的流程会在加载时自动清理旧数据里的标签 id，不需要重新录制。
- 流程文件位于 `plugin-data/dsh-agent-enhancer/demo-recipes.json`，只有本机可读，不含密码。

## 安装

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.18
```

或在 Desktop「设置 → 插件」里更新后重启。
