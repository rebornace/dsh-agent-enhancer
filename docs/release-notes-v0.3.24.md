# v0.3.24 — 流程里的值可以改、可以撤

## 新增

展开一个保存的流程，上面多了一块「可改的值」，每个值都能：

- **改名字**：直接改显示名（失焦生效），比如把「搜索」改成「本月关键词」。
- **改默认值**：下次运行默认用新值，不用每次重录。
- **每次问我**：不预填，运行前或对话里现问。适合日期、关键词这类每天都要换的值。打开后，对话里说「跑一下周报」就会先问你要日期。
- **改回固定值**：把 `${…}` 换回录制时的原文，变量消失，等于撤销参数化。

原来的参数化是单向的，误点一次只能重录；现在每一步都可逆，所有改动也进版本历史，仍可「撤销上次修改」。

## 说明

- 「每次问我」不会丢掉录制值：关掉它就回到原来的默认值。
- 密码类字段仍然不能变成变量。

## 升级

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.24
```

或在 Desktop「设置 → 插件」里更新后重启。
