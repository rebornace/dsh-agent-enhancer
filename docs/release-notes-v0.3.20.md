# v0.3.20 — 流程能改、能变、跑得更稳

## 新增

- **流程参数化**：展开保存的流程，给某个填写步骤点「设为参数」，例如把日期变成 `{from}`。旧值自动成为默认值，所以流程照常能跑。
  - 侧栏运行时会按变量逐个填写（已预填默认值）；
  - 智能体也能传变量：「跑一下周报导出，from 填 2026-11-01」；
  - 密码类字段不会变成变量。
- **查看与重命名**：点流程名展开步骤明细（编号 + 动作 + 选择器）；「重命名」就地改名，重名会被拒绝。

## 跑得更稳

- **晚渲染控件**：控件晚一步出现时最多重试 3 次（每次 600ms），SPA 水合慢半拍不再直接失败。
- **同名控件不点错**：页面上有多个同名按钮时，先用录制时的选择器判断是哪一个；判断不出来就停下并说明有几个候选，**绝不按名字点第一个**。
- **错误更具体**：找不到控件时带上当前 URL。

## 说明

- 不做「复制流程」：步骤不能编辑时，一份一模一样的副本没有用处；等参数化/步骤编辑能派生变体时再考虑。
- 参数只存在本机 `plugin-data`，不跟随会话删除。

## 安装

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.20
```

或在 Desktop「设置 → 插件」里更新后重启。
