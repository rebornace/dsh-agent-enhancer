# v0.3.19 — 保存的流程，智能体也能直接跑

## 新增

- **对话里直接调用已保存流程**
  - 「我保存过哪些流程？」→ 列出名称与步数。
  - 「跑一下『周报导出』」→ 按名字匹配（唯一片段即可，重名会拒绝并列出候选），重放前弹**一次**批准卡，写明流程名与步数。
  - 结果同样如实：跑完给每步 `ok` 和最终 URL；停在密码、找不到控件时给「停在第几步 + 原因 + 剩余步骤」。
- **重放支持下拉框与勾选框**
  - `<select>` 按 label 或 value 选中；
  - checkbox / radio 按录制时的勾选状态设置。
  - 只有密码、验证码、token 这类被掩码的字段仍会停下要人。

## 适合什么场景

- 每周固定的报表导出、后台审批：录一次，之后在对话里说一句就跑。
- 别人问你「这东西你能自动弄吗」：演示一遍 → 保存 → 智能体接手。

## 边界

- 流程只在本机 `plugin-data`，不随会话删除，也不会同步到别的机器。
- 页面改版后重放会停在找不到控件的那一步，不会乱点；改名或重录即可。
- 智能体运行流程需要演示录制开关打开，并且每次运行都有一次批准。

## 安装

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.19
```

或在 Desktop「设置 → 插件」里更新后重启。
