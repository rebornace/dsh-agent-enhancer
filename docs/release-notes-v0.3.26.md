# v0.3.26 — 权限选了「完全」就不再问

## 问题

把输入框下方的权限切到**完全权限**，浏览器操作仍然弹「浏览器操作待批准」。原因是插件自己那套批准卡不认识官方权限预设——它总是问一次。

## 现在

浏览器工具会读官方的权限预设，按你选的意思走：

| 你的选择 | 浏览器变更 |
| --- | --- |
| **完全权限** | 不再询问，直接执行 |
| **自动审查** | 由官方审查器裁决，我们的卡不再重复弹 |
| **仅可查看** | 直接拒绝，并提示切到「工作区内修改」或「完全权限」 |
| **工作区内修改** | 保留本地批准卡（浏览器在工作区之外，预设本身管不到） |
| 旧版宿主 / 找不到权限服务 | 保留本地批准卡，并在日志里说明一次原因 |

批准卡本身还在，只是不再和官方权限「各问一遍」。

## 升级

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.26
```

或在 Desktop「设置 → 插件」里更新后重启。
