# v0.3.22 — 参数说人话，流程自己长

## 参数不再要你起变量名

- **名字用页面上的**：保存的步骤里点「设为参数」，变量直接叫「开始日期」，机器标识自动生成，界面上看不到 `${from}`。
- **日期直接说人话**：运行或对话里都可以说「上周」「上周五」「本月」「上季度」或 `2026-11-01`，本机换算成具体日期。
- **缺值用一句话问**：智能体会问「这次开始日期用哪天？」，而不是回一串变量名。
- **保存后自动认领**：日期、邮箱、搜索词这类值会被点出来，一次一个「每次问我 / 保持固定」，不用自己翻步骤。
- **步骤明细口语化**：`在「开始日期」填 2026-11-01`，选择器不再占地方；日期变量给日期选择器。

## 流程能自己适应（可选）

设置 → 智能体增强 → 浏览器 Agent → **流程自动适应网站改版**（默认关）。打开后，网站改版导致的修复会直接记住，不再逐次询问：

- 只改「怎么找到控件」，绝不改填写的内容；
- 只在录制时的同一个网站内生效；
- 每个流程每天最多 3 次；
- 侧栏仍可「撤销上次修改」。

## 修复

- **「保存为流程」恢复**：0.3.20 的一次改动误删了保存分支，侧栏保存会掉进「运行」并报「流程不存在」。已恢复，并补了回归测试。

## 升级

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.22
```

或在 Desktop「设置 → 插件」里更新后重启。旧流程文件会自动升级（缺的字段补默认值，不丢流程）。
