# v0.3.29 — 流程列表：一行只放常用的

## 以前

一行里塞着「运行 / 重命名 / 删除」，删错了没有回头路；「无人值守」「撤销」藏在七行步骤下面，没人找得到。

## 现在

**收起时只有两件事**：

```
▸ 测试周报   6 步   [待确认修复] [无人值守]   [运行]  ⋯
```

- **运行** 是主按钮，永远在最显眼的位置；
- **⋯** 展开一条操作条：重命名 / 删除；删除要再点一次「确认删除」；
- 状态用小圆角标签表示（待确认修复、无人值守），那是状态，不是按钮。

**展开后按用途分区**（点流程名，前面的 ▸ 变成 ▾）：

- **可改的值**：名字、当前值、`☑ 每次问我`；「改回固定值」是文字链接，不是第四个按钮。
- **运行方式**：无人值守开关（附站点与时限说明）、版本号与「撤销上次修改」。
- **步骤**：默认收起，点「查看 6 步」才展开；步骤里的「设为参数」仍在每一行。

## 为什么菜单不是浮层

侧栏是滚动容器，浮层在列表底部会被裁掉。所以「⋯」展开的是一条行内操作条：不会被遮挡，键盘也能走到。

## 升级

```bash
dsh plugin --profile desktop add dsh-agent-enhancer@0.3.29
```

或在 Desktop「设置 → 插件」里更新后重启。
